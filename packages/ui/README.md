# @nft-marketplace/ui

Shared browser-safe React components for the marketplace design system.

The package exports accessible primitives, responsive layout helpers, forms,
tables, galleries, wallet and transaction status components, and CSS-variable
tokens through `@nft-marketplace/ui`. React 18 and 19 are supported as peer
dependencies. Import `@nft-marketplace/ui/styles.css` from the consuming app to
load the token and component styles.
