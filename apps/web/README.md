# @nft-marketplace/web

Next.js App Router gallery application. See `../../docs/T-050-implementation-guide.md` for route, API, wallet, and deployment details.

Run `yarn workspace @nft-marketplace/web dev` with `NEXT_PUBLIC_API_BASE_URL` pointed at the NestJS API. An optional `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` enables WalletConnect.
